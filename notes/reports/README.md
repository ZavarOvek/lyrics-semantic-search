# About these reports

These reports were written as deliverables against a set of internal
planning specifications, referenced throughout as `SPEC-00` through
`SPEC-04` with section numbers. Those planning documents are not part of
this repository. The references are left intact because they are part of
the historical record; each report is otherwise self-contained about what
was done and why.

Reports are append-only. Figures that were later corrected are left as
originally written, with the correction recorded in the later report that
found it.
