# About these decision notes

These notes hold design rationale that outlives any single phase: why a
choice was made, where it is enforced in code, and what evidence supports
it.

They were written alongside a set of internal planning specifications,
referenced throughout as `SPEC-00` through `SPEC-04` with section numbers.
Those planning documents are not part of this repository. The references
are left intact because they are part of the historical record; each note
is otherwise self-contained about what was decided and why.
